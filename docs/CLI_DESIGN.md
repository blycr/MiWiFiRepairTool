# CLI 界面设计文档（字符版）

> 纯命令行交互版（无 GUI）。进度条 / 状态指示 / 交互方案在此设计与迭代。
> 实现位于 `rust/crates/app/src/cli.rs`。

---

## 设计目标

1. **终端为尊**：终端（TTY）下用 ANSI 清屏重绘固定布局状态视图，每秒刷新；
   重定向/管道下自动退化为日志 + 周期状态摘要，**绝不输出 ANSI 污染**。
2. **进度条兼容一切终端**：用 ASCII 块 `[####------]`（不依赖 ▓░ 字形），颜色用 ANSI（终端）或纯文本（非终端）。
3. **刷机安全**：Ctrl+C 经 `SetConsoleCtrlHandler` 安全清理（恢复网卡）后退出；
   连接检查（45s 告警 / 300s 自动停止）与 GUI 版一致。

---

## 一、主菜单（纯命令行静态交互）

**无渲染线程**：每次动作后重打印一次菜单（tty 清屏重画，非 tty 滚动打印）——
零屏闪、零输入冲突、光标稳定。**自动识别仍生效**：每次显示时自动扫描网卡与
程序目录 `.bin`（复制新固件进目录后，下一次显示菜单即出现）。

```
小米路由器修复工具 (Rust v0.2.0) — 命令行版
刷机包目录（自动识别 .bin）：C:\...\MiWiFiRepairTool

 [1] 网卡    : WLAN  [192.168.31.40]  74:4C:A1:82:7F:E3  (1.20 Gbps)
 [2] 刷机包  : miwifi_r4_firmware_f1bbb_2.26.145.bin（自动识别，15.6 MB）
 [3] 开始刷机
 [4] 使用说明
 [0] 退出

 [16/08 15:46:01.123] [INF] 检测到新刷机包：my_rom.bin（自动识别）

输入编号 > _
```

- 单线程、无竞争：提示/反馈直接打印，动作结果（"无效输入"、"请先选择网卡…"、
  下载失败等）同时写入日志区，重画后仍可见；
- Ctrl+C：专用监控线程响应（主菜单阶段无网卡改动，直接安全退出）；
- **流程闭环**：刷机停止/完成后回到主菜单，可再次选择继续操作，最后才 `[0]` 退出。

## 二、刷机包自动识别（核心改进）

**不需要用户手动输入路径**（Windows 下手输路径易错：引号/空格/中文/盘符）。方案：

1. **自动扫描**：每次进入 `[2]` 自动扫描**程序目录（exe 同目录）**下扩展名为 `.bin`（不区分大小写）的文件，按文件名排序列出编号；
2. **唯一候选自动选中**：目录里只有一个 `.bin` 时启动即自动选中，直接 `[3]` 开始；
3. **云端下载落点即目录**：从云端下载的固件天然落在程序目录 → 自动进入候选列表并选中；
4. **手动输入降级为高级选项**（`[3]`，附提示"容易出错，推荐复制到程序目录或云端下载"）；
5. **下载大小校验不阻断**：云端列表的 size 并不可靠（实测 4Q：列表 9962408 字节 vs 实际 10080288 字节），
   下载后大小不一致时**保留文件并打警告**（`[WRN] ... 已按实际大小保留，不影响刷机`），
   固件按实际字节由 TFTP 传输；文件保留在程序目录 → 自动识别立即可见，无需重载；
6. **刷机前固件复制到程序目录**（TFTP 根），保证与路由器请求的文件名一致。

```
 刷机包目录（自动识别 .bin）：C:\...\MiWiFiRepairTool
 自动识别到 2 个刷机包：
   [1] miwifi_r4_firmware_f1bbb_2.26.145.bin（15.6 MB）
   [2] my_rom.bin（10.0 MB）
  ----------
   [3] 从云端列表下载
   [4] 手动输入路径（高级，不推荐）
   0 返回
 输入编号 > _
```

无候选时提示：`[1] 从云端列表下载（推荐）` / `[2] 已复制 .bin 到程序目录？按回车重新扫描` / `[3] 手动输入路径（高级）`。

## 三、下载进度条（单行原地刷新）

```
 下载 miwifi_r4_firmware_f1bbb_2.26.145.bin [########--------] 53%  1.2 MB/s
```

- `\r` + `\x1b[2K` 原地重绘，不滚屏；
- 非终端：不打进度（避免 \r 污染），仅完成/失败日志。

## 四、刷机状态视图（终端，每秒清屏重绘）

```
========== 刷机进行中 ==========
网卡 : 以太网  [192.168.31.1]  1C:83:41:C1:DA:FF  (1.00 Gbps)
DHCP : 设备 路由器 (1C:83:41:C1:DA:FF → 192.168.31.101)
TFTP : [############--------] 65%  1.2 KB/s  块 231  重传 0  miwifi_r4_....bin
连接 : [正常] 最近活动 3 秒前
----------------------------------------
[16/08 15:30:01.234] [INF] 刷机服务已启动（DHCP 地址池 192.168.31.100 - .199）
[16/08 15:30:05.111] [DBG] Rcvd DHCP Discover Msg for IP 0.0.0.0, Mac 1C:83:..
[16/08 15:30:05.120] [DBG] OACK: <blksize=1468,timeout=5,tsize=15728640>
----------------------------------------
[按 Enter 打开操作菜单 · Ctrl+C 安全退出（恢复网卡）]
```

- 布局固定（面板 + 最近 12 行日志环形区），`\x1b[2J` 清屏重绘，无滚屏错位；
- **连接状态三色**：正常=绿 `[正常]`、45s 起=黄 `[注意]`/告警行、自动停止=红；
- 设备出现即显示 MAC → IP；TFTP 实时速率/块/重传。

### 运行中的状态流转

```
[等待]   DHCP: 设备 无（等待路由器请求）      连接: [正常] 最近活动 2 秒前
[45s]    连接: [告警] 已等待 47 秒无请求，300 秒将自动停止   + 日志 [WRN]
[300s]   自动停止 → 恢复网卡 → 打印 [自动停止] 提示 → 回主菜单
[设备]   DHCP: 设备 路由器 (MAC → 192.168.31.101)
[完成]   TFTP: 完成：15728640 字节，301 块，42 秒，重传 0 次
```

### 刷机完成（关键流程）

```
========== [完成] 刷机完成 ==========
网卡 : 以太网  [192.168.31.1]  ...
DHCP : 设备 路由器 (MAC → 192.168.31.101)
TFTP : 完成：15728640 字节，301 块，42 秒，重传 0 次
[完成] 固件已传输完成！请断电重启路由器（拔电源再插上）。
连接 : [正常] 最近活动 3 秒前
----------------------------------------
[按 Enter 打开完成菜单 · Ctrl+C 安全退出（恢复网卡）]
```

- 传输成功即置「刷机完成」状态：标题变绿 [完成]、面板提示断电重启、日志给出完整下一步指引；
- **完成菜单（按 Enter）**：`1=停止服务并回到主菜单（推荐） 2=继续监控 0=退出程序`；
- 选 1 → 停止 + 恢复网卡 → **回到主菜单**（可再刷一次/换固件/换网卡），满足"刷完机还要继续操作"的场景。

### 操作菜单（刷机中，按 Enter 呼出）

```
  [操作菜单] 1=停止并恢复网卡  2=继续  0=退出程序
  输入编号 > _
```

菜单显示期间置**模态**：渲染线程暂停重绘，菜单稳定显示（不会被下一帧刷掉），
连接检查/自动停止仍继续；选完恢复刷新。（无"使用说明"项——放在主菜单 [4] 提供。）

## 五、非终端模式（重定向 / 管道）

- 不渲染状态视图；logger 日志（含级别标签）照常输出到 stderr；
- 每 5 秒打印一行状态摘要到 stdout：

```
[状态] 设备 1C:83:41:C1:DA:FF → 192.168.31.101 · TFTP 65% 块231 重传0
```

## 六、交互与安全

| 场景 | 行为 |
| --- | --- |
| Ctrl+C（刷机中） | `SetConsoleCtrlHandler` 置位 → 渲染线程安全停止（恢复网卡）→ 打印提示 → 退出；主菜单 watchdog 在会话期间被门控（`menu_active`），不会抢先硬退出 |
| Ctrl+C（菜单中） | 主菜单 watchdog（200ms 轮询 `CTRL_C`）→ 直接退出（主菜单阶段无网卡改动，安全） |
| EOF（管道输入结束） | 刷机中等价于"停止并恢复"（`stop(true)`）后退出，进程不挂死；菜单中输入点视为返回 |
| **提权（不离开当前会话）** | 主进程（当前控制台）全程驻留跑菜单/DHCP/TFTP/监控；需要管理员的两件事（改网卡、防火墙）通过**瞬时提权子进程**完成：`ShellExecuteExW(runas)` + `SEE_MASK_NO_CONSOLE`（不创建新窗口）+ 等待句柄 + result 文件回报。**不弹新控制台、不整进程重启**；开始设置网卡弹一次 UAC，停止恢复网卡再弹一次（属正常流程）。子进程包 `catch_unwind`，panic 也写进 result 文件 |
| 提权失败（UAC 取消/netsh 失败） | 错误信息经 result 文件返回主进程，打印在**当前窗口**（不会闪退）；**set 部分失败（如防火墙）时子进程按原快照自回滚网卡**，主进程不再二次弹 UAC |
| 启动顺序 | **先 bind DHCP/TFTP（Windows 下绑定 67/69 无需管理员）→ 成功后再提权设网卡**；端口冲突在提权前即可失败，避免"提权→失败→再提权回滚"的连环 UAC |
| 防火墙规则 | netsh 命令按 token 逐个传参（整串会被当作子命令名而静默失败）；失败时明确报错而非假装成功 |
| **刷机完成去向** | 完成状态 → 完成菜单 `1=停止并回到主菜单（推荐）`，防止用户不知所措；主菜单可继续操作，最后才退出 |
| 单实例 | `CreateMutexW` 互斥（守卫存活整个进程，非临时值），防止多开（提权子进程跳过） |
| 终端渲染 | 启动时尝试启用 VT 序列（`SetConsoleMode`）；失败（老 conhost/重定向）自动降级为滚动输出，不打印字面 ANSI；tty 面板模式下日志关闭 stderr 回显，避免与清屏重绘交错 |
| TFTP 上传 | **WRQ（上传）一律拒绝**（ERROR code 2）：刷机只需 RRQ 下载；防止任意 LAN 主机覆盖程序目录文件（固件/租约/日志） |
| **安全软件拦截提示** | ARP 探测（SendARP/ICMP）、ARP 缓存清理（GetIpNetTable/DeleteIpNetEntry）、netsh、防火墙、UAC 提权等被安全软件拦截时**不再静默**：探测类经错误码区分（不在 ARP 表/超时=正常，权限类=拦截）触发 `probe::set_probe_warn_handler` 警告（30s 节流）；清理失败经回调警告；启动失败/网卡枚举失败/防火墙失败均带排查引导文案；`[4]` 帮助含"七、安全软件兼容"指引 |

## 七、已实测验证（本机）

- 主菜单输入 `0` 退出；`1` 选择网卡（链路速率显示，选择后主面板立即反映）；
- 刷机包自动识别：无 `.bin` 时提示下载/复制；放 2 个 dummy `.bin` 后列表识别、编号选择生效；
- `2 → 云端` 下载真实固件 **15.6MB 成功**，自动设为当前刷机包并加入候选列表；
- **大小不一致不再失败**：4Q 下载（列表 9962408 vs 实际 10080288 字节）→ 保留文件 + `[WRN]` 警告 + 自动入列选中；
- 主菜单 `[2]` 文案：候选未选时显示"程序目录有 N 个 .bin，按 [2] 选择"，不再误报"无 .bin"；
- 提权子进程模式：`--elevated-op set/restore`（netsh 设/恢复网卡 + 防火墙）→ 结果文件回报 + 退出码（不弹新窗口）；
- 主菜单：纯命令行静态交互（无渲染线程，零屏闪零冲突；每次显示自动扫描网卡/刷机包）；
- 刷机中操作/完成菜单：模态暂停渲染，菜单稳定显示；输入提示由渲染线程绘制（无光标错位）；
- `--selftest`：全部 PASS（DHCP/TFTP 回环 + 云端在线检查）。

## 八、审计后修复（本轮）

- 防火墙：`netsh` 按 token 传参 + 校验失败报错（原整串传参 → 规则从未生效，DHCP/TFTP 可能被 Windows 防火墙拦截）；
- 会话期 Ctrl+C：watchdog 加 `menu_active` 门控，刷机中由渲染线程安全恢复网卡（原 watchdog 全程存活，多数情况硬退出、网卡滞留静态）；
- DHCP 报文：`hlen` 加 16 上界（原 `chaddr[..hlen]` 可被远程包触发 panic）；活动时间只在报文校验通过后刷新；
- TFTP：WRQ 数据包 `n<4` 防下溢（原远程可触发会话线程 panic）；WRQ 全部拒绝；块号比较按 u16 回绕（>65535 块不再失败）；
- 状态视图 stdin EOF：先 `stop(true)` 再退出（原 join 渲染线程永不返回，进程挂死）；
- 单实例互斥：守卫改为存活到 main 结束（原 `if let` 临时值在语句结束即释放，互斥失效）；
- 手动/云端选择的固件：目录刷新时保留在候选列表（原被目录扫描替换，可能静默换刷另一个 .bin）；
- 下载/复制失败：删除半成品 .bin（原残留截断文件可能被自动识别选中刷入，变砖风险）；
- 旧会话线程迟到回调：按会话代次（epoch）丢弃（原可能在新会话中显示虚假"刷机完成"）；
- 提权 set 失败：子进程按原快照自回滚 + `catch_unwind` 写 result；`--elevated-op` 缺值报错退出（原静默落入交互菜单）；
- 恢复网卡失败：保留快照供重试（原 `take()` 后丢失，无法再恢复）；
- 非 DHCP 且快照无 IP：跳过 set address（原回退成静态 192.168.31.1，改错网络）；
- 自动识别/子菜单：无效输入给反馈；`[3]` 分项提示缺网卡/缺固件；网卡名含 `"`/`\` 拒绝刷机；
- 完成提示：emoji 改 ASCII（conhost 下 emoji 显示为 □）；非终端完成摘要只打印一次；失败摘要显示"TFTP 失败"而非"等待中"；
- DHCP 探测：ICMP 超时 1000ms → 300ms（减少 OFFER 延迟）；网卡枚举跳过 Loopback 伪接口；枚举溢出防护；
- 日志：tty 面板模式关闭 stderr 回显（原 Debug 级 eprintln 与每秒清屏重绘交错刷屏）；
- **安全软件拦截提示**（用户反馈：安全软件拦截 ARP 等命令但程序无提示）：SendARP/IcmpSendEcho/DeleteIpNetEntry 异常错误码（非"不在 ARP 表/超时"等正常结果）→ 30s 节流警告"很可能被安全软件拦截"；GetIpNetTable 失败 → ARP 缓存清理警告；网卡枚举失败 → 一次性警告；DHCP/TFTP 启动失败、网卡/防火墙配置失败 → 附排查引导（端口占用/白名单放行）；每次防冲突探测结果进 debug.log；`[4]` 帮助新增"七、安全软件兼容"。
