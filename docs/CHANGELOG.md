# 更新日志（Changelog）

## v0.1.0（第一版，2025-08-16）—— 当前代码基线

本项目为纯命令行重写（Rust），行为对齐旧版工具与 tftpd32 定制逻辑；
按 **EUPL 1.1** 发布（与上游 tftpd32 许可一致）。衍生关系与第三方声明见 [NOTICE.md](../NOTICE.md)。

### 功能

1. **云端刷机包**：从小米官方接口 `api.miwifi.com` 拉取型号列表并下载 ROM
   （含 `http://http://` 脏数据清洗、大小校验、失败清理半成品）。
2. **刷机包自动识别**：exe 同目录 `.bin` 自动识别；手动/云端选择在目录刷新时保留。
3. **自动网卡配置**：静态 `192.168.31.1/24`（瞬时提权，不弹新控制台、不离开当前会话）；
   停止时智能恢复（DHCP → DHCP，静态 → 原静态 IP/DNS）；set 失败自回滚，恢复失败保留快照重试。
4. **DHCP 服务器**：地址池 .100–.199，租约 2 天，全报文处理 + 防冲突探测（SendARP+ICMP）。
5. **TFTP 服务器**：RFC 1350 + 选项协商（blksize/tsize/timeout）、超时重传、块/速率统计；
   **只读下发（WRQ 上传一律拒绝）**。
6. **实时状态视图**：DHCP 设备 / TFTP 进度条 / 连接检查（45s 告警、300s 自动停止）、
   操作/完成菜单、Ctrl+C 安全退出（自动恢复网卡）。
7. **安全软件兼容**：ARP/ICMP 探测、ARP 缓存清理、netsh、防火墙、UAC 提权被拦截时
   明确警告 + 排查引导（`[4]` 帮助含「七、安全软件兼容」）。
8. **日志**：`debug.log` 恒记录全部级别（含每次探测与命令执行结果）。

### 可靠性（审计修复合入本版）

- **防火墙规则真实生效**：netsh 按 token 传参并校验结果（原整串传参导致规则从未添加）。
- **刷机中 Ctrl+C 网卡恢复**：会话期 watchdog 门控，由渲染线程安全恢复。
- **DHCP/TFTP 远程崩溃防护**：报文 hlen 上界、WRQ n<4 下溢校验。
- **状态视图 stdin EOF 挂死修复**：EOF 等价停止并恢复网卡后退出。
- 单实例互斥守卫、下载失败清理半成品、会话代次 epoch 防旧回调污染、
  提权子进程 `catch_unwind` + 自回滚、网卡枚举跳过 Loopback、ICMP 探测超时 1s→300ms、
  VT 序列显式启用（conhost 自动降级滚动输出）、tty 面板日志去重、ASCII 提示。

### 分发与合规（本版）

- **x64 与 x86（32 位）双架构**并行发布；
- 发布 zip 随附 `LICENSE`（EUPL 1.1）与 `NOTICE.md`；
- 反编译分析、C# 走查、旧版二进制等内部文档**仅本地保留**，不入公开仓库；
- 全项目禁用 emoji（代码/文档/界面均为 ASCII 或标准排版符号）。

### 已知限制

- 300 秒自动停止（非管理员）期间 UI 冻结约 60 秒（恢复网卡同步等待 UAC）；
- 刷机中网卡被拔/禁用无主动监控（自动停止时会尽力恢复并提示）；
- netsh 中文输出未做 GBK 解码（错误信息可能乱码，不影响功能判断）。
