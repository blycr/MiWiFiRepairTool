# CLI 交互设计

> 纯命令行交互版（无 GUI）：主菜单 / 实时接口诊断 / 自适应左右分栏精简操作对照 / 提权与安全退出规范。
> 实现位于 `rust/crates/app/src/{cli,guardian,layout,menu,session,status,help,util}.rs`。

## 设计目标

1. **终端为尊与零遮挡分栏**：终端（TTY）下自动探测控制台可视宽高（`GetConsoleScreenBufferInfo`）；
   宽度 `>= 96` 列时启用左右分栏（左栏显示主界面/状态与实时日志，右栏固定 36 列展示精简操作对照与
   指示灯速查，左栏按 CJK 宽字符与 ANSI 色彩感知精确截断并闭合颜色，**绝不溢出或遮挡右侧**）；
   窄终端（`< 96` 列）自动退化为上下堆叠；重定向/管道下自动退化为无 ANSI 滚动摘要。
2. **实时接口与物理链路检测**：每秒实时监测有线/无线（WLAN）、网线物理通断与协商速率、
   `192.168.31.100` 生效态、DHCP/TFTP 监听态，以及后台非阻塞 `192.168.31.1` 正常态探测，
   精准提示错选 WLAN、未插网线、误插路由器 WAN 口或路由器仍在正常系统未进刷机模式。
3. **进度条兼容一切终端**：用 ASCII 块 `[####------]`（不依赖特殊字形）。
4. **刷机安全**：单次 UAC 守护进程保障停止、自动收尾、Ctrl+C 乃至崩溃均可自动恢复网卡；
   启动时检测断电残留 `nic_backup.json` 提供一键恢复。

## 一、主菜单（纯命令行静态交互 + 右侧精简对照）

无后台渲染线程，每次动作后重画一次（tty 宽屏左右分栏，窄屏上下堆叠，非 tty 滚动打印），零屏闪、光标稳定。
每次显示自动刷新网卡（有线网卡优先排序，标注 `[有线]`/`[无线]`，选到无线网卡或断链即时提示）与程序目录 `.bin`。

```
小米路由器修复工具 (Rust v0.2.0) - 命令行版                | === 精简操作对照 ===
刷机包目录（自动识别 .bin）：C:\...\MiWiFiRepairTool       |   准备: 电脑有线口 -> 路由器LAN口
                                                           |         (切勿插WAN口或外网网线)
 [1] 网卡    : [有线] 以太网  [192.168.1.50] (1.00 Gbps)   | v 1. 按[1]选连接路由器的有线网卡
     [就绪] 有线接口物理链路已接通, 请确认插路由器LAN口    | v 2. 按[2]选或下载 .bin 刷机包
 [2] 刷机包  : miwifi_r4_...bin（自动识别，15.6 MB）       | > 3. 按[3]开始刷机(仅弹一次UAC)
 [3] 开始刷机                                              |   4. 拔路由器电->按Reset再插电
 [4] 使用说明                                              |   5. 橙灯闪松手, 蓝灯闪=成功!
 [0] 退出                                                  |
                                                           | === 指示灯速查 ===
 输入编号 > _                                              |   橙灯常亮 : 正在启动
```

- 刷机包来源清晰区分：`自动识别` / `云端下载` / `手动选择`；
- 手动选择的目录外文件直接由 TFTP 单文件只读托管，**不再复制到程序目录**，刷新菜单时也不会被覆盖；
- **流程闭环**：刷机停止/完成后回到主菜单，可继续操作，最后才 `[0]` 退出。

## 二、云端下载与进度条

```
 下载 小米路由器 4 [########------------] 42%  3.5 MB/s
```

- 终端下用 `\r\x1b[2K` 单行原地刷新；非终端不打印进度污染日志；
- 流式写入 `<文件名>.part`，校验 HTTP `Content-Length`；
- 下载期间暂停主菜单硬退出 watchdog，按 Ctrl+C 会优雅中止下载、关闭句柄并删除 `.part`，
  绝不留下损坏的半成品 `.bin` 被下次启动自动选中。

## 三、刷机状态视图（终端，每秒自适应左右分栏重绘）

```
========== 刷机进行中 ==========                     | === 精简操作对照 ===
网卡 : [有线] 以太网 [192.168.31.100] (100 Mbps)     | v 1. 网线连电脑有线口与路由器LAN口
固件 : miwifi_r4_firmware_f1bbb_2.26.145.bin         |      (切勿插路由器WAN口/外网线)
接口 : [接口正确] 有线已对接路由器LAN口 (100 Mbps)   | v 2. 拔掉路由器电源, 按住Reset不松
服务 : DHCP/TFTP 已就绪 (192.168.31.100:67/69)       | v 3. 重新插电, 见橙灯闪后松开Reset
DHCP : 路由器 04:67:61:9A:3A:3C -> 192.168.31.101    |      (Mesh机型等紫灯常亮再松手)
TFTP : [############------] 65%  1820.5 KB/s         | > 4. 等待固件传输完成(切勿断电)
连接 : [传输中] 正在向路由器下发固件                 |   5. 待蓝灯闪烁=成功, 断电重启!
------------------------------------------------     |
[20/11 20:15:01.234] [INF] 刷机服务已启动...         | === 指示灯速查 ===
...                                                  |   蓝灯闪烁 : 刷机成功(请断电重启)
------------------------------------------------     |   红灯闪烁 : 刷机失败(换包重试)
[Enter] 操作菜单  [Ctrl+C] 安全退出(自动恢复网卡)    | === 快捷键 ===
```

- **实时接口诊断（`接口 :` 行）**：
  - 错选无线网卡：`[错选WLAN]` 红色强提醒改选有线网卡；
  - 物理断链：`[未连接]` 提示网线未插或路由器断电中（拔电按 Reset 时属正常）；
  - 链路接通且 `192.168.31.1` 在线：`[未进模式]` 提示路由器仍在正常系统，请拔电按住 Reset 重插电；
  - 链路连续接通 `>= 20s` 仍无请求：`[疑插错口]` 提示确认插在路由器 LAN 口（非 WAN 口）且按住 Reset；
  - 收到路由器 DHCP/TFTP 请求：`[接口正确]` 绿色确认网口对接无误。
- **右侧动态步骤高亮**：随链路通断、收到请求、TFTP 传输与完成状态自动推进当前 `>` 高亮步骤。
- **连接检查逻辑**：
  - 综合 DHCP 与 TFTP 最近活动时间；
  - **TFTP 传输中**：恒显示绿色 `[传输中]`，绝不触发空闲告警；
  - **传输完成后**：标题变绿 `[完成] 固件传输完成`，提示“请勿断电，待路由器蓝灯闪烁后再断电重启”，不再弹出误导性告警；静置 300s 自动收尾恢复网卡；
  - **等待路由器请求阶段**：45s 无活动告警（告警文案结合实时接口诊断给出精准原因），300s 自动停止并提示按 Enter 返回主菜单。

### 操作/完成菜单（按 Enter 呼出，模态暂停重绘）

- 刷机中：`[操作菜单] 1=停止并恢复网卡  2=继续  0=退出程序`
- 完成后：`[刷机完成] 1=停止服务并回到主菜单（推荐）  2=继续监控  0=退出程序`

## 四、非终端模式（重定向 / 管道）

- 不渲染 ANSI 状态视图；日志照常输出到 stderr；
- 每 5 秒打印一行状态摘要到 stdout，完成后仅打印一次完成提示。

## 五、交互与安全矩阵

| 场景 | 行为 |
| --- | --- |
| 开始刷机（非管理员） | 先预检 UDP 67/69 空闲 → 仅弹**一次 UAC** 静默启动守护进程（无新控制台）→ 设静态 `192.168.31.100/24` + 防火墙 → 精确绑定 DHCP/TFTP |
| 正常停止 / 选 `0` 退出 | 向守护进程发 `restore` 指令 → 恢复原网卡 + 删防火墙规则 + 删 `nic_backup.json`，**无需二次 UAC**；状态视图返回 `StatusExit` 协作退出，无竞态 |
| Ctrl+C（刷机中） | 渲染线程与主线程共享幂等 `stop(true)`，区分 Ctrl+C 与 stdin EOF，协作退出并自动恢复网卡，绝不双弹 UAC |
| 进程崩溃 / 点窗口 `X` 强关 | 命名管道断开 → 后台守护进程自动按快照恢复网卡与防火墙规则 |
| 整机断电 | 下次启动检测到 `nic_backup.json` → 提示 `[Y/n]` 一键恢复原网卡配置 |
| 网线暂未插好（Media Sense） | 静态 IP 写入后若暂不可绑定，DHCP/TFTP 后台每 500ms 自动等待链路就绪，路由器一上电即刻绑定 |
| 第三方安全软件禁用 Windows 防火墙 | 防火墙规则添加/删除失败仅记录明确警告，不阻断刷机与网卡恢复 |
| 路由器指示灯引导 | 与原版官方工具一致：橙灯常亮=启动中，橙灯闪烁=刷机中，紫灯常亮=Mesh 刷机中，蓝灯闪烁=刷机成功（需断电重启），红灯闪烁=失败 |

提权管道协议与会话数据流详见 [architecture.md](architecture.md)。
